# Consent Transport is the one part of crystal-core that isn't stdlib-only.
# It needs real, audited crypto primitives (X25519, Ed25519, ChaCha20-
# Poly1305, ML-KEM-768) that Python's standard library doesn't provide.
#
#     pip install -r requirements-consenttransport.txt
#
# The floor is 47, not 41: ML-KEM (NIST FIPS 203) landed in `cryptography`
# 47.0.0 as `hazmat.primitives.asymmetric.mlkem`, and the default Starline
# handshake is hybrid post-quantum. Verified by installing each release in
# a clean venv — 46.0.0 has no `mlkem` module, 47.0.0 does. On an older
# version the handshake refuses to start and says so, rather than quietly
# falling back to classical-only.
cryptography>=47
